# 方正喵嗚繁體 (FZMWFW--GB1-0) 繁體中文環境深度修復版

本專案收錄原始版本與針對繁體中文環境（特別是 Android / iOS / Windows）進行字圖分離、碼位補全與語系宣告修正的「方正喵嗚繁體」字型檔。

---

## 📌 修復背景與問題說明

原始發行的 `方正喵呜繁体.ttf` 雖然名為「繁體」，且內部繪製的字形也為繁體樣式，但在繁體中文語系環境（如台灣 zh-TW、香港 zh-HK）直接使用時會遇到兩大嚴重問題：

### 1. `OS/2` 表代碼頁宣告缺失
* 原版字型在 OpenType `OS/2` 表的 `ulCodePageRange1` 僅宣告了 `Bit 18` (Simplified Chinese PRC / CP936) 與 `Bit 0` (Latin 1)。
* **未開啟** `Bit 17` (Traditional Chinese Big5 / CP950)，導致 Android 系統的字型匹配引擎（Minikin）判定該字型不支援繁體中文，引發頻繁跳回系統黑體。

### 2. GB 12345 編碼「一簡對多繁」歷史錯位（最致命原因）
* 原版字形在製作時源自 GB 12345 編碼標準。在簡體規範中多個字被合併（如「舍/捨」、「只/祇/隻」、「后/後」）。
* 方正早期製作該 GB 繁體字庫時，為每個簡體位置硬性指定了一個繁體字形：
  * **「舍」** 被畫成帶 扌 旁的「**捨**」，導致「宿舍」顯示為「宿捨」。
  * **「只」** 被畫成帶 礻 旁的「**祇**」，導致「只是」顯示為「祇是」。
  * **「后」與「後」** 碼位字形相反，導致「皇后」顯示為「皇後」、「後面」顯示為「后面」。
  * **「征」與「徵」** 碼位字形相反，導致「長征」顯示為「長徵」、「特徵」顯示為「特征」。
  * **「里」** 被畫成「**裏**」，導致「公里」顯示為「公裏」。
  * **「松」** 被畫成「**鬆**」，導致「松樹」顯示為「鬆樹」。
  * **「干」** 被畫成「**幹**」，導致「天干/干擾」顯示為「幹擾」。
  * **「台」** 被畫成「**臺**」，缺乏獨立的「台」字。
  * **缺少「隻」與「麵」** 等常用繁體字。

---

## 🛠️ 修復內容

1. **開啟 Big5 代碼頁宣告**：
   * 修改 `OS/2.ulCodePageRange1`，加入 `Bit 17`（Traditional Chinese Big5 / CP950），數值更新為 `0x60001`。
   * Android、Windows 等系統現可正確將此字型識別為繁體中文支援字型。

2. **精確字圖手術與一簡多繁分離**：
   * **舍 / 捨 分離**：自同作者同格同風格之簡體原版移植無扌旁之正宗「**舍**」，原字圖獨立為「**捨**」(`U+6368`)。
   * **只 / 祇 / 隻 分離**：移植正宗「**只**」，原字圖獨立為「**祇**」(`U+7947`)，補全「**隻**」(`U+96BB`)。
   * **后 / 後 修正**：校正交換互倒的「**后**」(`U+540E`) 與「**後**`(`U+5F8C`)。
   * **征 / 徵 修正**：校正交換互倒的「**征**」(`U+5F81`) 與「**徵**`(`U+5FB5`)。
   * **里 / 裏 / 裡 分離**：移植正宗「**里**」，原字圖獨立為「**裏**」(`U+88CF`) 與「**裡**」(`U+88E1`)。
   * **松 / 鬆 分離**：移植正宗「**松**」，原字圖獨立為「**鬆**」(`U+9B06`)。
   * **干 / 幹 / 乾 分離**：移植正宗「**干**」，原字圖獨立為「**幹**」(`U+5E79`) 與「**乾**`(`U+4E7E`)。
   * **台 / 臺 分離**：移植正宗「**台**」，原字圖獨立為「**臺**」(`U+81FA`)。
   * **補全「麵」**：加入「**麵**」(`U+9EB5`)。

3. **繁體 Unicode 碼位映射擴展**：
   * 透過 `cmap` 表重新映射，將 **2,341 個常用繁體漢字碼位**精準關聯至字庫中已有的繁體字圖輪廓。
   * **總字元數由 7,814 個擴充至 10,155 個**（常用 Big5 一級漢字覆蓋率達 94% 以上）。
   * **雙向相容**：同時完整保留簡體碼位映射，輸入繁體或簡體皆能正常顯示對應繁體字形。

4. **`name` 表語系資訊補充**：
   * 新增 Language ID 1028（台灣 zh-TW）與 Language ID 3076（香港 zh-HK）的字型名稱記錄：`方正喵嗚繁體`。

## 💡 使用方式

* **Android (Magisk / KernelSU / 模組 / 主題)**：可直接將修復版字型更名為替換目標（如系統字型或自訂字型），或於字型模組中引用。
* **Windows / macOS**：直接點擊右鍵安裝即可在 Word、PS 等軟體中選用「方正喵嗚繁體」。
