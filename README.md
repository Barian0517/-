# 方正喵嗚繁體 (FZMWFW--GB1-0) 繁體中文環境全套終極修復版

本專案收錄原始版本與針對繁體中文環境（特別是 Android / iOS / Windows）進行**全套一簡多繁字圖分離、全量 Big5（一級＋二級）100% 補全、熱門顏文字/表情符號支援、軒及所有人名同音字補齊與 Big5 語系宣告修正**的「方正喵嗚繁體」字型檔。

---

## 📌 修復背景與問題說明

原始發行的 `方正喵呜繁体.ttf` 雖然名為「繁體」，但因底層製作源自 1990 年中國大陸的 **GB 12345 規範**，在繁體環境下存在數大系統性缺陷：

1. **`OS/2` 表缺少 Big5 代碼頁宣告**：
   * 原版未開啟 `Bit 17` (Traditional Chinese Big5 / CP950)，導致 Android 系統字型引擎（Minikin）判定字庫不支援繁體中文，引發頻繁跳字與 fallback 至系統黑體。

2. **「一簡對多繁」歷史字圖混淆與缺字**：
   * 簡體中文常將多個繁體字簡化合併為一個字（例如「舍/捨」、「只/祇/隻」、「后/後」、「制/製」、「谷/穀」）。
   * 早期 GB 繁體字庫硬性為每個位置指定單一字圖，導致大量字詞在繁體系統下顯示錯亂（如：宿舍變宿捨、只是變祇是、皇后變皇後、後面變后面、特徵變特征、長征變長徵、公里變公裏、松樹變鬆樹、郁蔥變鬱蔥、人云變人雲、准許變準許、山谷變山穀等）。

3. **熱門顏文字（如 `(⁎⁍̴̛ᴗ⁍̴̛⁎)`）在 LINE / Messenger 缺字與掉字**：
   * 顏文字常用的變音重疊符號（結合符號）與特殊標點（如 `⁎`、`⁍`、`̴`、`̛`、`ᴗ` 等）在原版字庫中完全缺漏。在通訊軟體（LINE、Messenger 等）中顯示時，由於結合變音符號無法在字庫中找到對應標註，會導致整組顏文字變成方塊豆腐塊 `□` 或整段隱形消失。

4. **大量二級常用字、同音字、人名罕見字缺失**：
   * 原版僅收錄 GB 基本字集，使得包含「**軒**」的眾多同音字（如：**琁、嬛、玹、諠、翾、禤、愃、楥、鋗、蕿、塇、駽、蝖、箮、衒** 等）以及 Big5 二級漢字在輸入或瀏覽時頻繁跳回黑體。

## 🛠️ 全量修復項目清單

### 1. 開啟 Big5 代碼頁宣告
* 修改 `OS/2.ulCodePageRange1` 開啟 `Bit 17`（數值更新為 `0x60001`）。
* 補全 `name` 表 Language ID 1028（台灣）與 3076（香港）之名稱宣告：`方正喵嗚繁體`。

### 2. 熱門顏文字與表情符號 100% 完整支援
補全 LINE、Messenger、Dcard、PTT 常用的特殊符號與變音符號：
* **閃亮星星眼顏文字 `(⁎⁍̴̛ᴗ⁍̴̛⁎)`**：
  * `⁎` (U+204E)、`⁍` (U+204D)、`̴` (U+0334 重疊波浪)、`̛` (U+031B 翹角眼睫毛)、`ᴗ` (U+1D17 微笑嘴巴)
* **其他熱門顏文字符號**：
  * `(๑•̀ㅂ•́)و✧`、`(◕‿◕✿)`、`(ง •_•)ง`、`(இдஇ; )`、`( ˘ ³˘)♥`、`(ﾉ>ω<)ﾉ`
  * 支援字符：`๑` (泰文)、`و` (阿拉伯打氣手)、`ง` (泰文握拳)、`இ` (哭哭眼睛)、`◕`、`◔`、`✧`、`✦`、`✿`、`❀`、`ㅂ`、`｡`、`･`、`ﾉ`、`³` 等。

### 3. 全量 Big5（一級常用 5,401 字 ＋ 二級次常用 7,652 字）100% 完整覆蓋
收字總量由原本的 7,814 字擴充至 **16,711 字**：

### 5. 「症 / 癥」字圖獨立分離與 Emoji Fallback 相容性優化
* **症 (U+75C7) 與 癥 (U+7665) 精確分家**：修復原版字型將「症狀」之「症」誤植為 20 畫「癥」（疒+徵）的歷史遺留錯誤，自原版簡體字庫提取正宗「疒+正」字圖注入，讓「症狀、急症、重症」不再誤顯為「癥」。
* **Emoji Fallback 相容性維持**：字庫嚴格維持為純粹中文字型，不包含任何 Emoji 碼位，確保系統原生彩色 Emoji（Noto Color Emoji）能夠順利 fallback 顯示官方彩色黃臉表情符號。
