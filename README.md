# 方正喵嗚繁體 (FZMWFW--GB1-0) 繁體中文環境修復版

本專案收錄原始版本與針對繁體中文系統（特別是 Android / iOS / Windows）進行深度修復與碼位補全的「方正喵嗚繁體」字型檔。

---

## 📌 修復背景與問題說明

原始發行的 `方正喵呜繁体.ttf` 雖然名為「繁體」，且內部繪製的字形也確實為繁體樣式，但在繁體中文語系環境（如台灣 zh-TW、香港 zh-HK）直接使用時會遇到嚴重的「缺字」與「跳回系統預設字型」問題：

1. **`OS/2` 表代碼頁宣告缺失**：
   * 原版字型在 OpenType `OS/2` 表的 `ulCodePageRange1` 僅宣告了 `Bit 18` (Simplified Chinese PRC / CP936) 與 `Bit 0` (Latin 1)。
   * **未開啟** `Bit 17` (Traditional Chinese Big5 / CP950)，導致 Android 系統的字型匹配引擎（Minikin）判定該字型不支援繁體中文。

2. **GB 編碼字形對應錯位（最致命原因）**：
   * 原版字形在製作時源自 GB 編碼標準，雖然每個字符輪廓畫成了繁體漢字，但其 Unicode `cmap` **僅綁定在簡體碼位上**。
   * 例如：「體」字被綁定在 `U+4F53`（体）而非 `U+9AD4`（體）；「嗚」字被綁定在 `U+545C`（呜）而非 `U+55DA`（嗚）。
   * 當在繁體系統下顯示實際繁體文本時，系統尋找繁體碼位因字庫中無對應記錄，直接判定缺字並觸發 fallback，換回系統預設黑體。

---

## 🛠️ 修復內容

1. **開啟 Big5 代碼頁宣告**：
   * 修改 `OS/2.ulCodePageRange1`，加入 `Bit 17`（Traditional Chinese Big5 / CP950），數值更新為 `0x60001`。
   * Android、Windows 等系統現可正確將此字型識別為繁體中文支援字型。

2. **繁體 Unicode 碼位映射補全**：
   * 透過 `cmap` 表重新映射，將 **2,341 個常用繁體漢字碼位**精準關聯至字庫中已有的繁體字圖輪廓。
   * **總字元數由 7,814 個擴充至 10,155 個**（常用 Big5 一級漢字覆蓋率達 94% 以上）。
   * **雙向相容**：同時完整保留簡體碼位映射，無論輸入繁體或簡體皆能正常顯示對應繁體字形。

3. **`name` 表語系資訊補充**：
   * 新增 Language ID 1028（台灣 zh-TW）與 Language ID 3076（香港 zh-HK）的字型名稱記錄：`方正喵嗚繁體`。

## 💡 使用方式

* **Android (Magisk / KernelSU / 模組 / 主題)**：可直接將修復版字型更名為替換目標（如系統字型或自訂字型），或於字型模組中引用。
* **Windows / macOS**：直接點擊右鍵安裝即可在 Word、PS 等軟體中選用「方正喵嗚繁體」。
